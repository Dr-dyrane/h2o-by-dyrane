# H₂O spatial experience

H₂O is composed as one continuous spatial journey rather than a stack of animated sections.

## Invariants

- Scroll controls authored movement across X, Y, and Z axes; motion must preserve reading orientation.
- WebGL carries atmosphere and continuity. Navigation, project evidence, actions, and reading surfaces remain semantic HTML.
- The interface is borderless. Separation comes from depth, scale, light, rhythm, and negative space—not hairlines or inset rings.
- Project descriptions stay below 25 words; the memorable statement leads and proof remains factual.
- Desktop and mobile receive independent choreography. Mobile is not a compressed desktop canvas.
- Reduced-motion users receive the complete story as a linear semantic composition.
- The ending restores the DYRANE signature as an authored closing frame, not a conventional footer.

## Verification

`scripts/verify-visual.mjs` captures the hero, spatial method, flagship chapters, horizontal archive, contact, and signature at desktop and mobile viewports. It fails on horizontal overflow, broken media, border leakage, excessive project copy, missing semantic structure, or page errors.
